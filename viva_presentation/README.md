## 🔒 Important Privacy Note for GitHub
* In Git and GitHub, repository permissions apply to the **entire repository**. Individual subfolders in a public repository cannot have separate privacy permissions.
* If you want to keep this entire project or your viva notes private from other students or visitors:
  1. Open your repository on GitHub: `https://github.com/ankitsingh0311/ChronoXSync`
  2. Navigate to **Settings** (top right tab).
  3. Scroll down to the **Danger Zone** at the bottom.
  4. Under **Change repository visibility**, click **Change visibility** and select **Make private**.
  5. Only you and your authorized collaborators will be able to view this repository and this folder.
